🤖 Cấu Hình Trợ Lý AI Check Nghĩa

Hệ thống hỗ trợ 2 chế độ kiểm tra nghĩa tiếng Việt thông minh:
  • Bộ phân tích ngữ nghĩa tích hợp (Mặc định): Chạy tức thì 100% trên trình duyệt không cần mạng, đối chiếu từ đồng nghĩa, gốc từ và bối cảnh.
  • Gemini AI API (Nâng cao): Đánh giá như giáo viên bản xứ, phân tích sắc thái ngữ pháp và độ tự nhiên.
API key chỉ được lưu trong trình duyệt của bạn (LocalStorage) và không gửi đi đâu khác. Nếu để trống, hệ thống sẽ sử dụng Bộ phân tích ngữ nghĩa tích hợp sẵn.
